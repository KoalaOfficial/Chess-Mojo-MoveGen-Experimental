    **Szczegółowe wyjaśnienie funkcji `BishopAttacksTemplate`**

Ten kod to implementacja **ataków gońca** (bishop attacks) przy użyciu techniki **Hyperbola Quintessence** (tej samej, którą wcześniej przerabiałem Ci z C++). Jest napisany w **Mojo** i używa `SIMD[DType.uint8, 64]` zamiast zwykłego `uint64_t`.

### 1. Co robi ta funkcja?

Przyjmuje planszę jako `SIMD[uint8, 64]` (czyli 64 elementy po 1 bajcie) i zwraca `SIMD[uint8, 64]`, w którym na pozycjach atakowanych przez gońca jest `1`, a na pozostałych `0`.

Działa tylko dla **jednego** gońca o podanym `PieceID`.

### 2. Krok po kroku – wyjaśnienie kodu

```mojo
@always_inline
def BishopAttacksTemplate[PieceID: UInt8](board: SIMD[DType.uint8, 64]) -> SIMD[DType.uint8, 64]:
```

- `@always_inline` – wymusza wklejenie funkcji w miejscu wywołania (dla wydajności).
- `PieceID` – parametr szablonowy (compile-time). Dzięki temu kompilator może wygenerować osobną wersję funkcji dla białego i czarnego gońca.

#### Krok 1: Znalezienie pozycji gońca

```mojo
var bishop_mask = board.eq(PieceID)           # SIMD[bool, 64] – gdzie jest goniec
var bishop_bitmask = bishop_mask.cast[DType.uint8]()  # zamiana na 0/1
var packed = PackMask(bishop_bitmask)         # spakowanie do UInt64 (bitboard)
if packed == 0:
    return SIMD[DType.uint8,64](0)            # nie ma gońca – zwracamy zera
```

- `board.eq(PieceID)` – porównuje każdy element SIMD z `PieceID` i zwraca maskę logiczną.
- `PackMask()` – to kluczowa funkcja. Zamienia 64-elementowy wektor `0/1` w pojedynczą liczbę `UInt64` (klasyczny bitboard).

#### Krok 2: Obliczenie pozycji gońca

```mojo
var index = Int(count_trailing_zeros(packed))
```

- Znajduje pozycję najniższego ustawionego bitu → to jest indeks pola, na którym stoi goniec (0–63).

#### Krok 3: Przygotowanie zajętości planszy

```mojo
var occupancy_mask = board.ne(0)                    # wszystkie pola, na których coś stoi
var occupancy_bitmask = occupancy_mask.cast[DType.uint8]()
var occupancy = PackMask(occupancy_bitmask)
```

- `occupancy` = bitboard ze wszystkimi figurami na planszy (w tym oba kolory).

#### Krok 4: Klasyczna technika Hyperbola Quintessence (dla przekątnej)

```mojo
var bishop_bit = UInt64(1) << UInt64(index)
var diagonal = BISHOP_DIAGONALS[index] & ~bishop_bit   # maska przekątnej bez pola gońca

var forward1 = occupancy & diagonal
var reverse1 = ReverseBits(forward1)

forward1 -= bishop_bit
reverse1 -= ReverseBits(bishop_bit)

forward1 ^= ReverseBits(reverse1)
var attacks1 = forward1 & diagonal
```

To jest dokładnie ta sama sztuczka co w Twoim wcześniejszym kodzie C++:

1. `forward1 = occupancy & diagonal` – bierzemy zajętość tylko na tej przekątnej.
2. Robimy wersję "odwróconą" (`reverse1`).
3. Odejmujemy bit gońca od obu wersji.
4. Robimy XOR i maskujemy z powrotem.
5. Wynik `attacks1` = wszystkie pola atakowane przez gońca wzdłuż **tej** przekątnej (aż do pierwszej figury blokującej).

#### Krok 5: To samo dla antyprzekątnej

```mojo
var antidiagonal = BISHOP_ANTIDIAGONALS[index] & ~bishop_bit

var forward2 = occupancy & antidiagonal
var reverse2 = ReverseBits(forward2)
forward2 -= bishop_bit
reverse2 -= ReverseBits(bishop_bit)
forward2 ^= ReverseBits(reverse2)

var attacks2 = forward2 & antidiagonal
```

Identyczna operacja, tylko dla drugiej przekątnej gońca.

#### Krok 6: Połączenie wyników + konwersja z powrotem do SIMD

```mojo
var final_attacks_bitboard = attacks1 | attacks2     # obie przekątne razem

var result = SIMD[DType.uint8,64](0)
for i in range(64):
    if (final_attacks_bitboard & (UInt64(1) << UInt64(i))) != 0:
        result[i] = 1
return result
```

- Łączymy ataki z obu przekątnych (`|` = OR).
- Na końcu ręcznie konwertujemy klasyczny bitboard z powrotem na `SIMD[uint8, 64]`.

### 3. Porównanie z Twoim wcześniejszym kodem C++

| Element                    | Wersja C++ (poprzednia)      | Wersja Mojo (obecna)              | Komentarz |
|---------------------------|------------------------------|-----------------------------------|---------|
| Reprezentacja planszy     | `U64` (uint64_t)             | `SIMD[uint8, 64]`                 | Mojo używa SIMD zamiast bitboarda |
| Pakowanie do bitboarda    | —                            | `PackMask()`                      | Konwersja SIMD → UInt64 |
| Odwracanie bitów          | `_byteswap_uint64`           | `ReverseBits()`                   | To samo |
| Technika ataków           | Hyperbola Quintessence       | Hyperbola Quintessence            | Identyczna |
| Maska przekątnej          | `smsk[sq].diagonalMaskEx`    | `BISHOP_DIAGONALS[index]`         | Prekomputowane tablice |
| Wynik                     | `U64`                        | `SIMD[uint8, 64]`                 | Konwersja z powrotem |

### 4. Zalety i wady tego podejścia

**Zalety:**
- Bardzo szybkie (ta sama technika co w Stockfishie / topowych silnikach).
- Działa w czasie stałym (O(1)).
- Łatwo przenieść do Mojo/SIMD.

**Wady:**
- Wymaga prekomputowanych tablic `BISHOP_DIAGONALS[64]` i `BISHOP_ANTIDIAGONALS[64]`.
- Ręczna konwersja `SIMD ↔ UInt64` na początku i końcu (to kosztuje trochę wydajności).
- Kod jest dość niskopoziomowy i trudny do czytania.

def PawnGeometry[PieceID: UInt8,PawnTable](board: SIMD[DType.uint8, 64]) -> PawnData:
    var result = PawnData(
        UInt64(0),

        UInt64(0)
    )

    var packed = PackMask(pawn_bits)

        result.en_passant_left |= pawn.en_passant_left
        result.en_passant_right |= pawn.en_passant_right


        packed &= packed - UInt64(1)


    return result

@always_inline
def HyperbolaAttacks(occupancy: UInt64,piece_bit: UInt64,line_mask: UInt64) -> UInt64:
    var mask = line_mask & ~piece_bit

    var forward = occupancy & mask
    var reverse = ReverseBits(forward)

    forward -= piece_bit
    reverse -= ReverseBits(piece_bit)

    forward ^= ReverseBits(reverse)

    return forward & mask


@always_inline

    return (

        ((x & 0x000000000000FF00) << 40) |
        ((x & 0x0000000000FF0000) << 24) |
        ((x & 0x00000000FF000000) << 8 ) |
        ((x & 0x000000FF00000000) >> 8 ) |
        ((x & 0x0000FF0000000000) >> 24) |
        ((x & 0x00FF000000000000) >> 40) |
        ((x & 0xFF00000000000000) >> 56)
    )

def dump_mask(label: String, mask: UInt64) -> None:
    print("=== ", label, " ===")
    print("raw:", mask)
    print("set bits:", bit_count(mask))

    for rank in range(8):
        var line = ""

        for file in range(8):
            var index = UInt64(rank * 8 + file)

            if ((mask >> index) & 1) != 0:
                line += "1 "
            else:
                line += ". "

        print(line)

    print()


@always_inline
def bit_count(mask: UInt64) -> Int:
    var count = 0
    var temp = mask
    while temp != 0:
        temp &= temp - UInt64(1)  # Czyści najniższy ustawiony bit
        count += 1
    return count
