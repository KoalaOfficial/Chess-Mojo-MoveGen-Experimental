#Chess-Mojo-MoveGen-Experimental

An experimental chess move generator written in **Mojo**.

This project demonstrates experimental chess move generation using custom algorithms. It is the first public phase of a larger chess engine research project.

## Features

* Experimental move generator written in Mojo

* Separate move generation logic for individual pieces
* Research-focused architecture
* Licensed under MIT

## Project Status

The move generator is nearly complete and released as an experimental milestone.

The long-term goal is to design a completely new chess engine architecture, inspired by modern evaluation techniques, while simultaneously exploring alternative mathematical representations of chess positions.

## Why Mojo?

This repository demonstrates that Mojo can be used for non-trivial experiments and sketches in systems programming, such as generating chess moves and performance-oriented algorithms.
